# Software Design Principles Catalogue

This index acts as a quick reference registry for all software design principles. To dive deeper into a principle, read its dedicated markdown file.

- **[DWIM (Do What I Mean)](principles/dwim.md)**: Modules should anticipate user intent and automatically handle boilerplate configuration internally to ensure a "pit of success".
- **[Principle of Least Surprise](principles/least-surprise.md)**: System behavior, interfaces, and defaults should align with standard conventions and natural user expectations.
- **[Principle of Least Privilege](principles/least-privilege.md)**: Components and users should be granted only the absolute minimum permissions needed to perform their intended function.
